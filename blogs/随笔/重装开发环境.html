重装开发环境 ​

前端开发

  1. vscode
  2. 安装nvm来管理多版本的node.js node.js (nodejs自带npm包管理工具。yarn包管理工具需要另外安装)
  3. vue-cli (vue的脚手架。安装它也安装了vue。通过npm来安装vue-cli)
  4. nginx

后端开发

  1. git
  2. jdk(配置JAVA_HOME环境变量，在path环境变量中添加JAVA_HOME)
  3. mysql (密码设置为123456，有时候需要安装依赖包：Microsoft Visual C++ 2019 Redistributable Package (x64))
  4. navicat（安装破解版）
  5. idea (安装破解版，注意配置maven)
  6. redis (安装windows版本的redis，密码设置为123456)
  7. RedisDesktopManager (redis数据库管理工具)
  8. maven(配置MAVEN_HOME环境变量，在path环境变量中添加MAVEN_HOME。注意修改maven配置文件中的本地仓库地址，远程仓库地址，编译环境信息)
  9. nacos（微服务注册中心，安装可选。若启动nacos闪退，检查是否配置了JAVA_HOME环境变量）
  10. xftp,xshell（可选）

PS:

  • maven的1.x版本需要配置MAVEN_HOME环境变量。2.x,3.x版本的maven需要配置M2_HOME环境变量

其他软件

  1. 360压缩
  2. edge浏览器或者chrome浏览器(注意安装vue插件)
  3. foxmail（邮件管理工具,注意导入邮件）
  4. 微信（注意导入聊天记录）
  5. QQ
  6. wps
  7. 安装windows版本的kindle (阅读pdf电子书)
  8. 滴答清单（待办事项管理）
  9. potplayer(好用的视频播放器)
  10. 向日葵（可选）
